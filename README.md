**Live site:** https://shivamsolves.github.io/Shivam-Professional-Portfolio/

## Sections

- **Hero:** terminal-style intro with a typing role line and quick links
- **About:** profile photo, stats and a short bio
- **Skills:** tabbed skill cards
- **Projects:** filterable project cards
- **Contact:** contact details and message form

Also includes a dark / light theme toggle, a downloadable resume ([My Resume.pdf](My%20Resume.pdf)), and a responsive layout for mobile and desktop.

## Run locally

No build step or dependencies needed.

```bash
git clone https://github.com/ShivamSolves/Shivam-Professional-Portfolio.git
cd Shivam-Professional-Portfolio
# open index.html in your browser
```

Or serve it with Python:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
